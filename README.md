# 🌙 Lunatory

### Offline-first inventory management for restaurants and multi-location operations

Lunatory is an independently developed, self-hosted inventory and logistics platform designed to make real-world inventory faster, simpler, and more reliable.

It combines mobile inventory workflows, barcode scanning, local/on-device vision features, offline operation, centralized synchronization, backups, and multi-store support.

> **Independent software project**

## ✨ Highlights

- 📱 Android inventory application
- 🖥️ Self-hosted server companion
- 📴 Offline-first operation
- 🔄 Server synchronization and reconnect support
- 🏪 Multi-store architecture
- 📦 Storage → Place → Category → Item organization
- 🔎 Inventory search and filtering
- 📷 Live camera inventory recognition
- 🏷️ Barcode and QR recognition
- 🤖 Local/offline vision processing where supported
- 📊 Par-level and usage tracking
- 🚚 Truck/order workflow tools
- 💾 Backup and restore
- 👥 Role-based users
- 🔐 PIN-based shared-device access

## 🧪 Current Development Status

Lunatory is under active development and real-world testing. Features, compatibility, deployment requirements, and licensing terms may change as the project matures.

Before relying on Lunatory for business-critical inventory data:

1. Review the release notes.
2. Back up existing data.
3. Test the intended workflow in your environment.
4. Verify backup **and restore** behavior.
5. Keep at least one independent backup of important business records.
