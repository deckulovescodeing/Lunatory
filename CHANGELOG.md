- Improved application stability
- Improved Android installation reliability
- Improved inventory persistence
- Improved storage/place/category/item workflows

### Server and Offline Use

- Improved server startup and reconnect behavior
- Improved handling of temporary server outages

### Live Vision and Scanning

- Improved live camera analysis

### Testing

Expanded testing includes:

- inventory creation and editing

- persistence across restarts
- server restart/reconnect testing
- backup and restore testing
