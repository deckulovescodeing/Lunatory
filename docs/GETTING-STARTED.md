# Getting Started with Lunatory

Lunatory is distributed as compiled releases. The production source code is maintained privately.

## 1. Choose a Release

Download only official Lunatory builds published through the Releases section of the official repository.

Verify that the release version shown in the release notes matches the installer or package filename.

## 2. Back Up Existing Data

Before installing an update or replacing an existing Lunatory deployment, create an independent backup of important inventory and business data.

A backup should not be considered trustworthy until restore behavior has also been tested.

## 3. Install the Intended Components

A deployment may include one or more of the following depending on the release:

- Android application
- self-hosted server companion
- Windows workstation/server package
- Linux server package

Follow the release-specific instructions rather than assuming every release uses the same packaging.

## 4. Configure Your Environment

Typical setup includes:

- creating/configuring a store
- creating authorized users
- connecting client devices to the intended Lunatory server when server sync is used
- creating storage areas, places, categories, and inventory items
- verifying backup location and restore workflow

## 5. Test Before Production Use

Before relying on Lunatory for regular business operations, verify at minimum:

- app launch
- login/access control
- inventory creation and editing
- quantity changes
- search
- offline behavior where applicable
- reconnect behavior
- backup creation
- actual backup restoration
- barcode scanning
- camera/vision workflows where used
